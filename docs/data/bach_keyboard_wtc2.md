# Bach keyboard grammar corpus

The `bach_keyboard` grammar is learned from Knute Snortum's open digital
edition of J. S. Bach's *Well-Tempered Clavier, Book II*.

- Upstream: https://github.com/ksnortum/bach-well-tempered-2
- Imported release: `v0.1`
- Imported format: release MIDI assets
- License: Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0)
- Project use: open-source, non-commercial statistical grammar learning
- Generated aggregate: `skills/composition/genre/packs/baroque/bach-keyboard/grammar.yaml`

BWV 846 belongs to Book I and is excluded from this corpus. It is used only as
an external listening and symbolic-overlap reference. The restricted
KernScores encodings were inspected for compatibility and are not used to
train the checked-in grammar.
